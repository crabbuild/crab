# crab undo

Inspect staged changes and reverse the last detected reversible `crab adopt` or
`crab add` operation. If no reversible staged operation is found, the command
returns an error.

## Synopsis

```bash
crab undo [OPTIONS]
```

```bash
crab undo
crab undo --json
```
