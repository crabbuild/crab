# crab migrate

Rewrite Git history to convert large files into Crab pointers or restore Crab
pointers to full files. History rewriting changes commit IDs. Back up the
repository and coordinate with every contributor before applying it.

## Synopsis

```bash
crab migrate <SUBCOMMAND> [OPTIONS]
```

## Subcommands

| Command | Purpose |
| --- | --- |
| `crab migrate info` | Report file types above a size threshold that would benefit from tracking |
| `crab migrate import` | Convert large files in history to Crab pointers |
| `crab migrate export` | Convert Crab pointers back to full files in history |
| `crab migrate from-dvc` | Convert a `dvc.yaml` pipeline to `crab.yaml` |

## Examples

Inspect large-file extensions:

```bash
crab migrate info
crab migrate info --above 10485760 --top 5
```

Preview and then import selected files across all branches:

```bash
crab migrate import --include '*.bin' --include '*.safetensors' --dry-run
crab migrate import --include '*.bin' --everything
```

Export selected pointer-backed files from history:

```bash
crab migrate export --include '*.bin' --dry-run
```

Convert a DVC pipeline:

```bash
crab migrate from-dvc --dir . --output crab.yaml
```

Use `--stdout` with `from-dvc` to inspect the converted YAML without writing a
file.
