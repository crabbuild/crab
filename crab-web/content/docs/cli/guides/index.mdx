# Tutorials & Guides

Use these guides when you want a complete workflow, not a command reference.
Each guide starts with a goal, walks through the commands, and ends with checks
you can run to confirm everything is working.

## Learn Crab

- [Working with Files](/docs/cli/daily-workflow) — Add, commit, push, fetch, and hydrate in the order most teams use every day.
- [Sharing Repositories](/docs/cli/guides/sharing-repositories) — Set up a shared bucket and onboard collaborators.

## Migrate Existing Work

- [Migrating from Git LFS](/docs/cli/guides/migrating-from-lfs) — Move large-file history and team workflows from LFS to Crab.
- [Migrating from DVC](/docs/cli/guides/migrating-from-dvc) — Transition data pipelines to Crab-backed storage.

## Operate Crab

- [CI/CD Integration](/docs/cli/guides/ci-cd-integration) — Use Crab in automated build, training, and deployment pipelines.
- [Enterprise Authentication](/docs/cli/authentication/enterprise-auth) — Choose an auth model for a team or company.
- [Cache Service](/docs/cli/cache-service) — Deploy a shared cache for repeated clone, hydrate, and CI workloads.

For individual commands, use the [CLI reference](/docs/cli/reference).
