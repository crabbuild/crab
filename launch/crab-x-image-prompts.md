# Crab X launch image specification

The current launch visuals were created with the Baoyu article-illustration workflow using its `tech-explainer` preset: infographic type, blueprint style, English labels, and a 16:9 aspect ratio.

The canonical planning and prompt artifacts are:

- `imgs/outline.md` — placement, purpose, and exact topic mapping for all 20 images.
- `imgs/prompts/` — one complete structured prompt per image.
- `imgs/01-*.png` through `imgs/20-*.png` — the inspected publication assets.

Each post has exactly two images. Prompts are grounded in Crab's repository contracts and use concrete terms, flows, and values rather than generic cloud imagery. The set covers direct object-storage architecture, Git filters and remote helpers, pointer and reconstruction ownership, Gearhash chunking, xorb packing, CAS publication, lazy hydration, storage namespaces, reachability GC, LFS coexistence, mirror ordering, repair semantics, and contribution evidence.

The previous 3D concept-art prompt set is superseded and is not part of the launch deliverable. The launch series references only the source-backed blueprint assets under `imgs/`.
