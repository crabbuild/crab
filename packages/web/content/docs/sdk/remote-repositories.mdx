# Remote repositories

Remote APIs read and modify Crab repositories without a checkout, local Git
object database, Git executable, or Crab executable.

## Pinned reads

Select the remote interface once, then issue operations against its captured
generation:

```rust
use crab_sdk::{GitPath, Revision};

let remote = repository.remote()?;
let snapshot = remote.snapshot(Revision::branch("main")?).await?;
let pointer = snapshot.read_blob(GitPath::new("model.bin")?).await?;
let mut content = snapshot.open_file(GitPath::new("model.bin")?).await?;
while let Some(bytes) = content.next().await? {
    consume(bytes);
}
content.close().await?;
```

A `remote::Snapshot` provides commit metadata, paginated tree and history
traversal, diff, blame, raw blobs, hydrated files, and streamed archives.
`read_blob` returns exact Git blob bytes. With `content`, `open_file`
reconstructs and verifies referenced Crab or Git LFS content. Successful EOF
proves full-file integrity.

## Remote commits

With `write`, remote commits accept streamed replacements and deletions.
Hydrated edits publish verified content before their pointer enters the Git
tree.

```rust
use crab_sdk::remote::EntryMode;
use crab_sdk::remote::write::{CommitIdentity, CommitOptions, FileEdit};
use crab_sdk::GitPath;

let identity = CommitIdentity::new(
    "Build bot",
    "bot@example.com",
    1_800_000_000,
    0,
)?;
let commit = CommitOptions::new(
    snapshot.commit_id()?,
    "refs/heads/main",
    Some(snapshot.commit_id()?),
    identity.clone(),
    identity,
    b"Update model".to_vec(),
)?;
let prepared = remote
    .prepare_commit(
        commit,
        vec![FileEdit::hydrated(
            GitPath::new("model.bin")?,
            EntryMode::Regular,
            size,
            reader,
        )?],
        scratch_directory,
    )
    .await?;
persist(prepared.recovery_token().to_json()?);
let outcome = prepared.execute().await?;
```

Preparation never advances refs. `remote::write::RefBatch` applies branch and
tag creates, updates, and deletes atomically. Update and delete operations
include the expected old object ID. `WritePolicy::ForceWithLease` permits an
explicit rewrite while retaining that expectation.
