# crab du

Report disk usage for tracked files.

## Synopsis

```bash
crab du [OPTIONS]
```

## Description

`crab du` shows a disk-usage breakdown for Crab-managed local storage. Pass
`--remote` when you also want a remote storage size query.

## Options

| Option | Default | Description |
|--------|---------|-------------|
| `--remote` | `false` | Include remote storage size; requires network access |
| `-j, --json` | `false` | Emit machine-readable JSON output |

## Examples

### Full disk usage report

```bash
crab du
```

### Include remote storage

```bash
crab du --remote
```

The default report reads local state. `--remote` adds a network-dependent size
query and can take longer or fail independently of the local calculation. Use
the JSON form when comparing usage over time, and record whether remote data
was requested so two reports describe the same scope. This command reports
usage; it does not evict cached objects or delete remote data.
