# crab unmount

Unmount a Crab virtual filesystem mount.

## Synopsis

```bash
crab unmount [OPTIONS]
```

| Option | Description |
| --- | --- |
| `-m, --mountpoint <PATH>` | Unmount the filesystem at this path |
| `--all` | Unmount all active Crab mounts |

Examples:

```bash
crab unmount --mountpoint /mnt/models
crab unmount -m /tmp/view
crab unmount --all
```

Use [`crab mount`](/docs/cli/reference/crab-mount) to inspect and manage a
mount before unmounting it.

## Verify mount shutdown

Prefer an explicit mountpoint when a machine has more than one active mount.
`--all` is intended for maintenance or shutdown flows where every Crab mount
on the machine should stop. It is broader than unmounting the repository in
the current directory.

Inspect state before and after the operation:

```bash
crab mount status
crab unmount --mountpoint /mnt/models
crab mount status
```

The final status must no longer report the selected active mount. If a process
still has files open, the operating system or mount backend can delay or reject
shutdown; close readers and retry the same explicit path. Use `--all` only
after reviewing the mount list, because it can interrupt unrelated repository
views owned by the same Crab installation.

Unmounting removes the filesystem view. It does not delete repository objects,
working-tree files outside the mount, or cached data.
