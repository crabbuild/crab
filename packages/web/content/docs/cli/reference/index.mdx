# Crab CLI command index

This page reflects the current top-level command surface of the open-source Crab
CLI. Reference pages cover the higher-use commands and workflows. For the full
option set for any installed binary, run `crab <command> --help`.

Running `crab --help` shows these same top-level commands in task-oriented
sections. The sections are visual navigation only; commands remain directly
available as `crab hydrate`, `crab exp`, `crab gc`, and so on.

The CLI also exposes aliases such as `crab get` for `crab download` and
`crab repro` for `crab run`. Internal Git filter and remote-helper entry points
are intentionally omitted from this user-facing index.

## Repository setup and transfer

| Command | Purpose |
| --- | --- |
| [`crab configure`](/docs/cli/reference/crab-configure) | Guided cloud, credential, Git, and large-file setup |
| [`crab init`](/docs/cli/reference/crab-init) | Initialize or re-apply a Crab repository connection |
| [`crab setup`](/docs/cli/reference/crab-setup) | Scan for large files and configure tracking |
| [`crab clone`](/docs/cli/reference/crab-clone) | Clone a repository with Crab filter and hydration setup |
| [`crab mirror`](/docs/cli/reference/crab-mirror) | Mirror a Git remote into a Crab remote |
| [`crab download`](/docs/cli/reference/crab-download) | Download selected files without cloning |
| [`crab worktree`](/docs/cli/reference/crab-worktree) | Manage Crab-aware Git worktrees |
| [`crab import`](/docs/cli/reference/crab-import) | Import a raw object-storage prefix into a Crab-backed repository |
| [`crab export`](/docs/cli/reference/crab-export) | Export a Crab snapshot as materialized files |
| `crab install` / `crab uninstall` | Install or remove the Git filter driver |
