# crab env

Display environment and configuration info.

## Synopsis

```bash
crab env [OPTIONS]
```

## Description

`crab env` shows the Crab version and build metadata, Git version, configured
remote, Git filter/diff drivers, and selected storage-related environment
variables. It does not print secret credentials.

For conceptual background, see [Environment Info](/docs/cli/authentication/environment-info).

## Options

| Option | Default | Description |
|--------|---------|-------------|
| `--json` | `false` | Emit structured JSON output |

## Examples

```bash
crab env
crab env --json
```

Use the human view during interactive diagnosis. Use JSON when an incident tool
needs to record the same environment fields without parsing labels. Compare the
reported remote and Git filter configuration with the repository you intended
to inspect.

## Security boundary

The command reports selected environment-variable presence and configuration,
but it does not print secret credential values. Its output can still reveal
repository URLs, provider names, and local paths, so review it before attaching
it to a public issue. `crab env` is read-only and does not refresh credentials
or test remote access.

When environment data looks correct but an operation still fails, continue
with `crab auth status` for cached authentication state and `crab doctor` for
active health checks. Preserve all three outputs with the same Crab version so
the evidence describes one configuration state.
