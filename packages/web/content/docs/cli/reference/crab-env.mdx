# crab env

Display environment and configuration info.

## Synopsis

```
crab env [OPTIONS]
```

## Description

`crab env` shows the Crab version and build metadata, Git version, configured
remote, Git filter/diff drivers, and selected storage-related environment
variables. It does not print secret credentials.

For conceptual background, see [Environment Info](/docs/cli/authentication/environment-info).

## Options

| Option | Default | Description |
|--------|---------|-------------|
| `--json` | `false` | Emit structured JSON output |

## Examples

```bash
crab env
```
