# crab exp

Manage experiment runs and their local or remote metadata.

## Synopsis

```bash
crab exp <COMMAND>
```

## Commands

`run`, `show`, `diff`, `ls`, `promote`, `apply`, `save`, `rename`, `push`,
`pull`, `remove`, `clean`, `gc`, `queue`, `start`, `status`, and `stop`.

Each experiment is a DAG run against a temporary worktree. Metadata is stored
under `.crab/workflow/exp/`. Use `crab exp <command> --help` for the exact
parameters and queue controls for that command.

## Examples

### Run an experiment

```bash
crab exp run --set learning_rate=0.001 --set epochs=50
```

### List experiments

```bash
crab exp ls
```

### Compare two experiments

```bash
crab exp diff <experiment-a> <experiment-b>
```

Run `crab exp show <id>` or `crab exp diff` before applying or promoting an
experiment. Experiment metadata is local until a push operation shares it with
the configured remote. Applying a completed snapshot changes the current
workspace, while promoting creates a branch at the experiment's base commit;
inspect each subcommand help before choosing that boundary. Temporary worktrees
keep normal runs isolated from uncommitted workspace edits.
