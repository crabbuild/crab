# crab tier

Manage storage tier assignments.

## Synopsis

```bash
crab tier [OPTIONS] <COMMAND>
```

## Description

`crab tier` manages bucket lifecycle rules. It currently exposes `plan` to
generate a lifecycle plan and `rollback` to restore a prior configuration from
a backup file.

For conceptual background, see [Storage Tiers](/docs/cli/storage/storage-tiers).

Each subcommand exposes its own provider-specific options. Use
`crab tier <command> --help` for details.

## Examples

```bash
crab tier plan
crab tier plan --help
crab tier rollback --help
```

`plan` generates lifecycle rules without applying them unless `--apply` is
present. Review XML, JSON, or YAML output first, then use `--apply` only for the
intended bucket configuration. `--merge` preserves existing non-Crab rules
instead of rejecting a conflict. Before applying, retain the backup needed by
`rollback`; rollback accepts that backup file as a positional path.

Lifecycle rules change future provider transitions rather than rewriting every
object during the command. Verify the active provider configuration after
application and keep the plan with the maintenance record.
