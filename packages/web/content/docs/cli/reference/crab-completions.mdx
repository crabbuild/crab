# crab completions

Generate shell completion scripts for the current Crab command surface.

## Synopsis

```bash
crab completions [OPTIONS] <SHELL>
```

Supported shells are `bash`, `zsh`, `fish`, and `powershell`.

```bash
crab completions zsh > ~/.zsh/completions/_crab
crab completions bash
crab completions fish --install
crab completions powershell --install
```

`--install` writes to the shell-specific completion directory. Use
`crab completions <shell> --help` if your shell setup needs a different load
path.

## Load the generated script

Generating a script prints it to standard output unless `--install` is used.
This lets you inspect or place the file according to your shell configuration.
For zsh, make sure the destination directory is in `fpath` before shell
completion initialization. For bash, source the generated file from the
interactive shell startup configuration when your package manager does not
load it automatically.

Verify the generated content and start a new shell session:

```bash
crab completions zsh | head
exec zsh
```

Then type `crab ` and request completion. The script describes the command
surface of the installed Crab binary, so regenerate it after an upgrade that
adds commands or options. `--install` chooses Crab's shell-specific default
directory; explicit redirection remains the better choice when dotfiles or a
system package owns completion loading.
