# crab errors

Look up error codes and explanations.

## Synopsis

```bash
crab errors [OPTIONS] [CODE]
```

## Description

`crab errors` displays explanations for Crab error codes. Without an argument,
it lists known codes; with a code, it shows the explanation and suggested
remediation. Codes use the `CRAB-E####` form.

For conceptual background, see [Error Codes](/docs/cli/diagnostics/error-codes).

## Arguments

| Argument | Required | Description |
|----------|----------|-------------|
| `CODE` | No | Specific error code to look up (e.g. `CRAB-E0017`) |

## Options

| Option | Description |
| --- | --- |
| `--json` | Emit a structured JSON envelope |

## Examples

### Look up a specific error

```bash
crab errors CRAB-E0017
```

### List all error codes

```bash
crab errors
```

Copy the complete `CRAB-E####` value from the original failure. The lookup
explains the stable error category and suggested response, while the original
message and logs retain operation-specific details such as paths or provider
responses. Looking up a code is read-only and does not retry or repair the
failed operation. Use `--json` when an incident tool needs the explanation in a
structured envelope.
