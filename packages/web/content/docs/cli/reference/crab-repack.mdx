# crab repack

Consolidate remote Git pack files.

## Synopsis

```bash
crab repack [OPTIONS]
```

## Description

`crab repack` applies Git's geometric pack policy to remote Git pack files.
Over time, many pushes can leave many small packs in the remote. Repacking
rolls up the smallest required set and atomically updates the active pack list,
while leaving large stable packs intact. Immutable recovery history continues
to retain old packs by default, so repack first optimizes active reads. To
reclaim superseded storage, explicitly prune older recovery generations and
then run repository GC.

The command requires Capsule v2 authority. It opens the authenticated view from
the captured root and delegates to shared Capsule consolidation and checkpoint
publication. It does not publish a manifest-v1 inventory, legacy locator or
generation receipt. Root compare-and-swap protects newer authority. A competing
root replacement leaves this pass unpublished, with its input inventory in the
summary; actual body work remains reported. GC-fence conflicts and provider
failures retain their error classification and causes. Uncertain publication
retains evidence for reconciliation without blind retry.

Dry-run reads metadata without pack bodies or publication. It reports current
pack count/bytes and zero body-work counters, without estimating a replacement
size. Apply preserves stable-prefix sources and verifies selected replacements.
The summary describes this pass rather than a later writer's inventory.

For conceptual background, see [Repacking Objects](/docs/cli/storage/repacking-objects).

## Options

| Option | Default | Description |
|--------|---------|-------------|
| `--dry-run` | `false` | Show repack plan without executing |
| `--json` | `false` | Emit structured JSON output |
| `--jsonl` | `false` | Emit a terminal structured result event |

## Examples

```bash
crab repack --dry-run
crab repack
```
