# crab params

Read or compare flattened parameter maps across Git refs.

## Synopsis

```bash
crab params <COMMAND>
```

| Command | Purpose |
| --- | --- |
| `show` | Print the parameter map at a ref |
| `diff` | Emit a structured parameter diff between refs |

```bash
crab params show --help
crab params diff --help
```
