# crab logs

View and manage diagnostic logs.

## Synopsis

```bash
crab logs <COMMAND>
```

## Description

`crab logs` manages diagnostic log files. Use `last` or `show` to read a log,
`list` to discover names, and `clear` to delete all log files.

The default log level is `error`. Set `CRAB_LOG=debug` or pass
`--log-level debug` for a single troubleshooting run.

For conceptual background, see [Log Management](/docs/cli/diagnostics/log-management).

## Commands

| Command | Purpose |
| --- | --- |
| `list` | List all log files |
| `last` | Show the most recent log file |
| `show <NAME>` | Show a specific log file |
| `clear` | Delete all log files |

## Examples

### View recent logs

```bash
crab logs list
crab logs last
```

### Show a named log file

```bash
crab logs show <NAME>
```

### Delete log files

```bash
crab logs clear
```

List files before selecting `show`, because a displayed label and a filesystem
name may differ across releases. Capture `last` or the relevant named log before
running `clear`; clearing is destructive and removes every diagnostic log file
managed by this command. Logs can contain repository paths and provider
details, so review them before sharing outside the incident team.
