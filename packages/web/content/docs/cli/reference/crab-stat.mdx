# crab stat

Show staging, push-plan, and performance statistics.

## Synopsis

```bash
crab stat [OPTIONS] [COMMAND]
```

## Description

`crab stat` prints staging-area statistics by default. Its subcommands expose
performance counters, the add-time push plan, and per-storage-class totals.

## Options

| Option | Default | Description |
|--------|---------|-------------|
| `--json` | `false` | Emit structured JSON output |

## Commands

| Command | Purpose |
| --- | --- |
| `perf` | Print performance counters |
| `push-plan` | Print the add-time push-plan inventory; use `--verify` to verify payloads |
| `classes` | Print per-storage-class bytes and object counts |

## Examples

### Staging statistics

```bash
crab stat
```

### Push-plan verification

```bash
crab stat push-plan --verify --json
```

Choose the view that matches the question: the default for staged inventory,
`perf` for counters, `push-plan` for add-time transfer planning, and `classes`
for storage-class totals. `push-plan --verify` reads planned payloads and checks
their inventory before a push; it does not publish them. JSON output is useful
for comparing the same view across runs without parsing the human table.
